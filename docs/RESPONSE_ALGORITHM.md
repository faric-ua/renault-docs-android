## Схема відповіді

```
① СУТЬ — 1–2 речення
   Проєкт + що сталось / що робимо.

② ЩО ЗРОБЛЕНО — коротко, без історії
   Чесна сходинка стану:
   код → тести/CI → APK готовий →
   встановлено → пас на телефоні
   (CI ≠ пас; пас ставить лише faric)

③ ЩО ВАЖЛИВО ЗНАТИ (якщо є)
   Ризик, межа, чого ще нема.

④ ВІД ТЕБЕ ЗАРАЗ:  (завжди в кінці)
   • ПЕРШИЙ РЯДОК — значок установки:
     📲 СТАВИТИ: ТАК — <застосунок> <версія>
     🚫 СТАВИТИ: НІ — <чому, коротко>
   • 🔴 Якщо потрібна відповідь faric —
     яскравим блоком, повторювати в кожному
     повідомленні, доки не відповість.
   • Тестувати — так чи ні.
   • Меню: НАЗВА МЕНЮ → номери.
   • Перевірка: до 3 кроків максимум,
     кожен: дія → що має побачити.
   • Відповідь: «пас / не пас»,
     скрін — лише якщо щось не так.
   • Або прямо: «нічого не треба».
```

## Правила для всіх частин

- Звертатися «faric», українською, простими словами, коротко.
- Дії на телефоні — **лише пунктами меню**, спершу **назва меню** (як у шапці меню), потім номери: `RENAULT DOCS: 5 → 19 → 8 → 13`.
  Номери звіряти з самим меню в репо, не вигадувати. Команди — лише для аварійної діагностики, коли в меню нема пункту.
- Усе, що faric має скопіювати (текст, команду), — **окремим блоком коду**; перед блоком — куди вставити.
- **Дія — завжди в кінці**, у блоці «Від тебе зараз:». Першим реченням дію не ставити, навіть термінову
  (термінове питання — 🔴-блоком усередині «Від тебе зараз:»).
- **Значок установки — першим рядком «Від тебе зараз:», у кожній робочій відповіді** (faric 2026-10-18 14:15):
  `📲 СТАВИТИ: ТАК — Renodocs 0.6.4 (поверх)` або `🚫 СТАВИТИ: НІ — нового APK нема`. Без нього faric не розуміє, чи щось ставити.
  Не відомо, чи вже стоїть, — «📲 СТАВИТИ: ТАК, якщо в «Про програму» ще не <версія>». Значок не замінює 🔴-питання — 🔴 іде одразу під ним.
- **Перевірок — не більше 3** за раз; під час тесту — по одному кроку, якщо так простіше.
- Нема готового APK — тестів не давати. Те, що вже пройшло на телефоні, повторно не просити.
- Що можна перевірити кодом — Claude перевіряє сам; faric просять лише те, що видно тільки на телефоні.
- **M30s — запасний телефон для тестів.** Тести на ньому — лише коли faric скаже, що він вільний.
  Не нагадувати про них у кожному повідомленні й не ставити 🔴.
- **«Частина 1/3, 2/3, 3/3» (з YTM) у Claude не застосовується.** Правило зроблене для ChatGPT, який зависав
  і починав спочатку. Якщо чат Claude став великим і гальмує — перехід у новий чат (правило в `claude/КОНТЕКСТ.md` проєкту).
- Якщо faric просить інший формат конкретної відповіді — його слово важливіше за цей файл.
