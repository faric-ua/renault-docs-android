# Technical Blue — Concept Inventory

All concepts from the UI exploration are preserved.

## Variant A — tabbed single-column viewer

Status: **selected / approved-concept**

Key ideas:
- top app bar with Home, Search, Settings;
- native tabs: Sections / Illustrations / PDF / Contents;
- compact one-column section rows;
- PDF toolbar directly above document;
- best fit for portrait phones;
- avoids permanent side drawer.

Files:
- `reference-variant-a-selected.png`
- `concept-selected.svg` — canonical structural recreation;
- derived `concept-selected.png` and `concept-selected.pdf` are generated by CI.

## Variant B — permanent drawer

Status: archived alternative.

Key ideas:
- left navigation drawer permanently visible;
- content on right;
- useful on tablets/landscape;
- too expensive in horizontal space for ordinary portrait phones.

File:
- `reference-variant-b-drawer.png`

This remains useful as a **wide-screen layout reference**, not the default phone UI.

## Variant C — overlay drawer with top PDF controls

Status: archived alternative.

Key ideas:
- one-column menu overlays document;
- PDF controls stay at top;
- good source for the future phone menu/drawer behavior.

File:
- `reference-variant-c-overlay.png`

## Decision

For portrait phone UI:
**Variant A is the primary direction.**

Elements from B/C may be reused responsively:
- B for tablet/landscape two-pane layout;
- C for collapsible document menu/drawer.
