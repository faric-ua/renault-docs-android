# План: папка-архів томів + робочі копії в телефоні (2026-10-16)

_Ідея власника 2026-10-15 20:07 (аналіз — журнал 2026-10-15). Цей файл — детальний план для «так/ні» власника. Коду ще немає._

## Навіщо

- Імпорт 18 томів Megane II на карту M30s ішов ~23 год (15.10 ~03:00 → 16.10 ~02:30+): кожен том — тисячі дрібних файлів, і кожен проходить через службу медіа Android 11 (FuseDaemon). У пам'ять телефона 5 томів ставились за ~3 хв.
- Один великий файл на том на карті — швидко (карта 90 МБ/с), служба медіа бачить 1 файл, а не тисячі.
- Видиму папку власник бачить сам, вона переживає перевстановлення застосунку.

## Як буде виглядати

На карті пам'яті (корінь):

```
Renault Docs/
  .nomedia                      ← першим, до будь-якого файлу
  packages/                     ← один файл на том
    NT8446 Megane II 2006-03.rdpkg
    NT8494 Megane II.rdpkg
    …
  .service/                     ← службова, для застосунку
    projects.json               ← проєкти, томи, контрольні суми
```

- **Архів** = файл `.rdpkg` у `packages/`. Головна копія тому.
- **Робоча копія** = розпакований том у пам'яті телефона (`noBackupFilesDir`, не йде в бекапи). Лише з неї читаються сторінки.
- Галочка **«Тримати завжди»** — робоча копія не прибирається (свій автомобіль).
- Без галочки: робоча копія, яку не відкривали **N днів** (пропозиція — 30), прибирається сама, **лише якщо архів є і перевірений** (sha256). Сповіщення: «Звільнено N ГБ, архіви лишились».

## Стани тому (на екрані «Архів томів»)

| Стан | Що видно | Дія |
|---|---|---|
| Архів + робоча копія | ✔ | — |
| Лише архів | 📦 «відкриється за ~1 хв» | при відкритті — розпакування в телефон |
| Робоча копія без архіву | ⚠ «немає в архіві» | «Зберегти в архів» |
| Архів зник з папки | ⚠ «файл видалено з папки» | «Зберегти знову» (поки є робоча копія) |
| Файл у папці, якого немає в проєктах | ❓ | «Додати до проєкту» |

1. **Папка-архів.** Одноразовий дозвіл на карту (системне вікно «Дозволити доступ до папки»), створення `Renault Docs/` з `.nomedia`, екран «Архів томів» зі станами, кнопка «Зберегти в архів» (той самий `RdpkgExporter`, перевірка sha256 після запису). 4. **Відновлення.** Після перевстановлення: дозвіл на папку ще раз → застосунок читає `.service/projects.json` → проєкти й томи з'являються як «лише архів».

## Ризики й межі

- Перше відкриття тому «лише архів» — ~0,5–1 хв (розпакування). Далі — як зараз.
- Робоча копія займає місце в телефоні, поки її не прибрано (M30s: ~8 ГБ вільно).
- Якщо власник сам видалить файл з `packages/`, застосунок нічого не стирає — лише показує «файл видалено з папки».
- Дозвіл на папку Android може забрати (напр. після «Очистити дані» — ми цього не просимо); тоді застосунок попросить вибрати папку ще раз.
- Пізніше (не зараз): читати сторінки прямо з архіву без розпакування.
