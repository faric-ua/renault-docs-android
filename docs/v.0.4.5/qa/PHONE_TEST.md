# v0.4.5 Phone Test

1. Install v0.4.5 over v0.4.4.
2. Open any PDF.
3. Tap the small ▼ button beside the percentage field.
4. Expected: a visible popup appears with:
   - 85%
   - 100%
   - 120%
   - 150%
   - 200%
5. Select each preset and verify the PDF scale changes.
6. Open the popup and tap outside it: expected popup closes.
7. Horizontally scroll the PDF toolbar if needed, then open the popup again.
8. Expected: popup is still visible and positioned beside the button, not clipped by the toolbar.
9. Verify manual percentage input, −/+, Fit width and Save PDF still work.
