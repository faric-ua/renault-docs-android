# v0.4.0 Phone Test

1. Install v0.4.0 over v0.3.4.
2. Open the Library.
3. Confirm the Settings icon opens the Settings screen.
4. Change "Відкривати dataset" to Classic.
5. Return to Library and open Laguna.
6. Expected: dataset opens directly in Classic viewer.
7. Change back to Modern and verify Modern opens again.
8. Set PDF default zoom to 150%.
9. Set +/- step to 5%.
10. Open a PDF.
11. Expected: PDF starts at 150%; +/- changes by 5%.
12. Set default PDF zoom to "За шириною · 100%" and verify a newly opened PDF starts fit-width.
13. Select a backup folder.
14. Leave Settings and reopen it.
15. Expected: selected backup folder is still shown.
16. Confirm existing Fast Pack speed, PDF Save, zoom presets and fit-width button still work.
