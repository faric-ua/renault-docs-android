# Core

Спільний шар для браузера й Android.

Тут будуть:

- правила нормалізації шляхів;
- case-sensitive виправлення;
- обробка динамічних JS-посилань;
- побудова manifest;
- перевірка broken links;
- конвертація оригінальної документації у платформонезалежний статичний набір.

Core не повинен містити Android- або browser-specific логіку.
